# Evoke

Evoke is an AI and virtual reality project exploring how immersive digital environments can be used to preserve memories and create meaningful experiences for people experiencing memory loss.

The project aims to transform personal photographs, descriptions, music, and other meaningful information into interactive virtual environments that people can explore and revisit.

## Overview

Evoke is designed around the idea that familiar places and personal memories can be brought to life through virtual reality. Users can create digital environments inspired by meaningful locations, personal belongings, and shared experiences.

The platform is being developed with a desktop application for creating and managing virtual worlds and a VR application for exploring them. The goal is to make the process of creating personalized environments accessible without requiring users to have 3D modeling or game development experience.

## Planned Features

- **AI-Assisted World Creation:** Generate immersive environments using photographs, written descriptions, and other personal information.
- **Personalized Environments:** Create virtual spaces inspired by familiar homes, meaningful locations, and personal memories.
- **Desktop World Management:** Create, organize, and manage virtual environments through a desktop application.
- **Environment Editing:** Refine and modify generated worlds using additional descriptions and reference materials.
- **Cloud Storage:** Save and retrieve virtual environments through a connected account.



## Technology Stack

- Unity for VR application development
- Meta Quest 2 for virtual reality
- World Labs Marble API for 3D world generation
- Supabase for data management and asset storage
- GitHub for version control

## Motivation

Evoke was conceived as an exploration of how AI and virtual reality could be combined to create more personal and immersive experiences for people affected by memory loss.

Rather than relying exclusively on conventional photographs or videos, the project investigates whether interactive virtual environments can provide a more engaging way to revisit familiar places and meaningful experiences.

## Project Status

Evoke is an ongoing development project. Its planned functionality and technical implementation may evolve as development progresses.

The project is an exploration of AI-assisted 3D generation, virtual reality development, local AI inference, cloud infrastructure, and the potential applications of immersive technology in memory care.

**Note:** Evoke is an experimental project and is not a clinically validated treatment for memory loss or dementia.
