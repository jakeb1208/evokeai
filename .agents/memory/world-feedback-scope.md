---
name: World feedback scope
description: Product boundary for private memory-care world ratings.
---

World feedback belongs only in the desktop and website experience, not the Unity/Quest client. The five questions use one-to-three-star ratings, remain editable, and each user's worlds order by their own overall average rating.

**Why:** The user explicitly limited feedback to desktop and website, while keeping VR viewing separate.

**How to apply:** Do not add feedback prompts or controls inside VR. Keep feedback account-scoped and do not present these subjective ratings as validated memory or clinical outcomes.
